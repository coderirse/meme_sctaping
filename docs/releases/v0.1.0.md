# MemeCollector v0.1.0

首个定制版本，提供 Windows 与 Android 11+ 的主动表情收集、本地保存和双端互传。

## 主要功能

- Windows QQ 收藏缓存与微信收藏清单读取，多账号和手动数据目录，预览后仅保存勾选项。
- 安卓通过 Shizuku 读取 QQ 缓存，动图预览、只看未保存、取消任务和结果分类；微信按“手机添加 → 电脑收集 → 传回手机”的方式使用。
- PNG、JPEG、GIF、WebP 按内容识别，GIF / 动态 WebP 保留原始字节，SHA-256 去重。
- 修正 Shizuku 远程进程等待兼容性，批量读取 QQ 文件元数据，避免逐文件启动 shell。
- 独立 Android 包名和签名，Windows 用户级安装；默认本地使用，不自动安装上游更新。

## 验证

- 桌面测试 547 项通过、1 项跳过；安卓 JVM 测试 77 项通过。
- 安卓设备测试 4 项通过，另通过双端加密桥接设备测试及真实手机界面采集验证。
- vivo X100 Ultra / Android 16 实测保存 240×240、28 帧 GIF，原字节和哈希一致，未保存候选从 755 降至 754。
- 双端动态 WebP / GIF 往返、加密握手、设备确认及重复上传去重通过 USB TCP 转发验证。
- Windows 安装、启动入口、内置辅助程序和卸载验证通过；APK v2 签名验证通过。

## 已知边界

Android 11 实机、Wi-Fi 自动发现、防火墙环境、手机微信新收藏到电脑再传回的完整同步尚未补测。特殊商城表情和 QQ 超级表情不作为本版支持承诺。完整操作步骤见 [README](https://github.com/coderirse/meme_sctaping/blob/v0.1.0/README.md)，详细范围见 [验证记录](https://github.com/coderirse/meme_sctaping/blob/v0.1.0/docs/verification.md)。
